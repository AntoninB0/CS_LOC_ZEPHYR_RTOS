# ─────────────────────────────────────────────────────────────────────────
# Python environment for the UART chain:
#   uart_console.py  console: commands (IQON/IQOFF/AUTO/ORDER) + display of the
#                    decoded measurements with estimated distance
#   cs_decoder.py    decoding/validation/pairing of the IQL/IQP lines
#   estimation.py    distance estimation (phase + RTT)
# ─────────────────────────────────────────────────────────────────────────

# ── 1. Create the venv (once) ──────────────────────────────────────────────
#   cd tools
#   python3 -m venv .venv
#
# ── 2. ACTIVATE it (in every new terminal session) ─────────────────────────
#   Linux / macOS (bash, zsh):
#     source .venv/bin/activate
#   Windows PowerShell:
#     .venv\Scripts\Activate.ps1
#
#   -> the prompt shows "(.venv)" when it is active.
#
# ── 3. Install the dependencies (once, venv activated) ──────────────────────
#   pip install -r install.txt
#
# ── 4. Run ──────────────────────────────────────────────────────────────────
#   python uart_console.py --list                    # find the /dev/ttyACM*
#   python uart_console.py --port /dev/ttyACM0       # live (921600 by default)
#   python uart_console.py --file capture_ref_921600.txt   # offline replay
#
# ── 5. Deactivate (leave the venv) ─────────────────────────────────────────
#   deactivate
#
# Note: the venv (.venv/) is ignored by git (.gitignore). Recreate it with
# steps 1-3 on another machine.
# ─────────────────────────────────────────────────────────────────────────
