# ─────────────────────────────────────────────────────────────────────────
# Environnement Python pour la chaîne UART :
#   uart_console.py  console : commandes (IQON/IQOFF/AUTO/ORDER) + affichage
#                    des mesures décodées avec distance estimée
#   cs_decoder.py    décodage/validation/appariement des lignes IQL/IQP
#   estimation.py    estimation de distance (phase + RTT)
# ─────────────────────────────────────────────────────────────────────────

# ── 1. Créer le venv (une seule fois) ──────────────────────────────────────
#   cd tools
#   python3 -m venv .venv
#
# ── 2. L'ACTIVER (à chaque nouvelle session de terminal) ───────────────────
#   Linux / macOS (bash, zsh) :
#     source .venv/bin/activate
#   Windows PowerShell :
#     .venv\Scripts\Activate.ps1
#
#   -> l'invite affiche « (.venv) » quand c'est actif.
#
# ── 3. Installer les dépendances (une fois, venv activé) ───────────────────
#   pip install -r install.txt
#
# ── 4. Lancer ──────────────────────────────────────────────────────────────
#   python uart_console.py --list                    # repérer le /dev/ttyACM*
#   python uart_console.py --port /dev/ttyACM0       # live (921600 par défaut)
#   python uart_console.py --file capture_ref_921600.txt   # rejeu hors ligne
#
# ── 5. Désactiver (quitter le venv) ────────────────────────────────────────
#   deactivate
#
# Note : le venv (.venv/) est ignoré par git (.gitignore). Le recréer avec les
# étapes 1-3 sur une autre machine.
# ─────────────────────────────────────────────────────────────────────────
